# Glider for Hacker News

[<img src="https://play.google.com/intl/en_us/badges/images/generic/en_badge_web_generic.png" alt="Get it on Google Play" height="80">][play store]
[<img src="https://fdroid.gitlab.io/artwork/badge/get-it-on.png" alt="Get it on F-Droid" height="80">][f-droid]

Glider is an opinionated Hacker News client. Ad-free, open-source, no-nonsense.

- Browse stories, comments and user profiles
- Catch up on and search stories from any period
- Log in with your Hacker News account
- Vote on and favorite stories and comments
- Write replies and submit new stories
- Collapse comment trees
- No ads, no telemetry
- Extensive theming
- Sensible defaults

## Building

The toolchain is pinned in [`mise.toml`](mise.toml) (Flutter, Java and the
Android SDK), so setup is:

```sh
mise install          # installs the pinned Flutter, JDK and Android SDK
flutter pub get       # resolves the pub workspace (app + both packages)
```

This is a [pub workspace][workspaces] with two local packages under
`packages/`, driven by [Melos][melos]:

```sh
dart run melos run lint    # dart analyze + dart format --set-exit-if-changed
dart run melos run test    # app tests and package tests
flutter run                # debug builds install as `nl.viter.glider.debug`,
                           # so they sit alongside a store install
```

Release builds are signed from `android/key.properties`; without it a local
build falls back to the debug key, and the build fails outright in CI rather
than producing an unsigned artifact.

Launcher icons are generated by `flutter_launcher_icons`, which is not a
dev dependency because it conflicts with Melos on `cli_util`. Run it on demand:

```sh
dart pub global activate flutter_launcher_icons
dart pub global run flutter_launcher_icons
```
